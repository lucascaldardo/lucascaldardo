### 💻 Sobre mim

Sou um estudante de **Análise e Desenvolvimento de Sistemas** na FATEC, com forte foco na criação de APIs e arquitetura de software. Tenho um interesse enorme na intersecção entre tecnologia e o **mercado financeiro**. Trabalho priorizando arquitetura limpa, código organizado e soluções escaláveis.

* 🔭 **Atualmente trabalhando em:** Projetos práticos de backend, construção de APIs robustas usando **Spring Boot**, e participando de Hackathons focados em inovação.
* 🌱 **Estudando no momento:** Java, Spring Boot, SQL e boas práticas.
* 💼 **Objetivo:** Atuar como Desenvolvedor resolvendo problemas reais com código limpo.
